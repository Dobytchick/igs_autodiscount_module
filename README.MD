# Автоматические скидки для GM Donate

Скидки на товары [GM Donate](https://gm-donate.net/) по праздникам России и в выходные. Модуль получает календарь из [Nager.Date](https://date.nager.at/), пересчитывает цены при смене дня и возвращает исходную стоимость после акции.

## Возможности

- Праздничная скидка действует за заданное число дней до праздника и после него, включая переход через границы месяца и года.
- Скидка на выходных действует в субботу и воскресенье; при совпадении с праздником приоритет настраивается.
- Можно исключить категории и добавить собственные даты.
- Исходные цены и ранее заданное зачёркивание восстанавливаются после акции. Повторная загрузка модуля не суммирует скидки.
- Сервер рассчитывает скидку и передаёт её клиентам. Если сервис календаря недоступен, уже загруженные праздники сохраняются; запрос повторяется позднее. Скидка выходного дня работает независимо от сервиса.

## Установка

1. Установите и настройте GM Donate / IGS на сервере.
2. Скачайте [последний релиз](https://github.com/Dobytchick/igs_autodiscount_module/releases/latest) или [архив `main`](https://github.com/Dobytchick/igs_autodiscount_module/archive/refs/heads/main.zip).
3. Скопируйте папку `igs-modification` в `garrysmod/addons/`.
4. Настройте файл `igs-modification/lua/igs/modules/autodiscount/igs_autodiscount.lua` и **полностью перезапустите сервер**. При обновлении со старой версии полный перезапуск нужен для сброса уже изменённых цен.

## Настройка

Параметры находятся в начале [`igs_autodiscount.lua`](igs-modification/lua/igs/modules/autodiscount/igs_autodiscount.lua).

| Параметр | По умолчанию | Назначение |
| --- | ---: | --- |
| `BEFORE_START` | `12` | Дней до праздника; дата начала акции включена. |
| `HOLIDAY_DURATION` | `7` | Дней после даты праздника; последний день включён. |
| `HOLIDAY_DISCOUNT` | `50` | Процент праздничной скидки. |
| `WEEK_DISCOUNT_ENABLE` | `true` | Включить скидку в субботу и воскресенье. |
| `WEEK_DISCOUNT` | `20` | Процент скидки на выходных. |
| `IGNORE_WEEKEND` | `true` | При совпадении праздника с выходным применять праздничную скидку. При `false` приоритет у скидки выходного дня. |

Периоды `BEFORE_START` и `HOLIDAY_DURATION` задаются целым числом от 0 до 31, проценты — числом от 0 до 100. Некорректное значение останавливает загрузку модуля.

Для исключения категории или добавления своей даты раскомментируйте примеры в том же файле:

```lua
AddBlackCategory("Донат группы")
AddCustomHoliday("День сервера", "2026-12-31")
```

Название категории должно точно совпадать с названием в IGS. Дата собственного праздника задаётся в формате `ГГГГ-ММ-ДД`; для ежегодного события добавляйте дату нужного года. Расписание определяется часовым поясом сервера.

## Как работает расчёт

Модуль запрашивает праздники России за текущий год, а в январе и декабре также за соседний год. Для отдельного праздника с датой `1 января`, `BEFORE_START = 12` и `HOLIDAY_DURATION = 7` окно акции длится **с 20 декабря по 8 января включительно**. Соседние праздники могут продлить общий период скидки. Повторяющиеся записи «Новогодние каникулы» со 2 по 6 января не считаются отдельными праздниками.

Цены пересчитываются при загрузке, после ответа сервиса, при инициализации IGS, при входе игрока и затем раз в минуту. Проверка при входе нужна также после сна пустого сервера. Если HTTP-запрос завершился ошибкой, повторная попытка выполняется через час. Успешный календарь обновляется раз в сутки. Уведомления отправляются только при смене акции, затем повторяются раз в пять минут до её окончания.

Модуль изменяет цены обычных товаров IGS в памяти. Товары с `SetGetPrice` не участвуют в скидке: их цена рассчитывается отдельно. Если установлен хотя бы один обработчик `IGS.ItemPriceOverride` через `hook.Add` или `GAMEMODE`, автоматические скидки отключаются целиком, чтобы не показывать цену, отличающуюся от цены покупки. Если другой модуль меняет поле `price` во время акции, порядок изменений нужно согласовать вручную. При недоступном календаре после запуска праздничная скидка появится только после успешного ответа сервиса; выходная скидка доступна сразу.

## Проверка

Сценарии с отложенным HTTP-ответом, переходом через Новый год, окончанием акции, повторной загрузкой и синхронизацией клиента запускаются на Lua 5.1:

```sh
lua5.1 tests/autodiscount.lua igs-modification/lua/igs/modules/autodiscount/igs_autodiscount.lua
```

Тесты используют имитации API Garry’s Mod и IGS. Для проверки установки и отображения цен нужен работающий сервер Garry’s Mod с GM Donate.
